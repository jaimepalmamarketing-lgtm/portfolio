# Portfolio de Comunicación y Marketing Digital

Sitio estático preparado para GitHub Pages. El contenido visible y el CV no incluyen nombre, correo electrónico ni teléfono.

## Publicación
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. En Settings > Pages selecciona Deploy from a branch.
3. Selecciona la rama principal y /(root).

No requiere instalación ni servicios de pago.
